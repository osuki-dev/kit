# Code of Conduct

## The standard

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. Read it — it is the authoritative text and it is short.

## What it means here

Be direct about code and considerate about people. Reviews argue with the
change, not the person who wrote it. "This breaks dark mode on Android" is
useful; "this is careless" is not.

Specific to this project:

- Contributors work in several languages. English is the working language for
  issues and PRs, but imperfect English is never a reason to dismiss a report.
- A rejected contribution is a scoping decision, not a judgement of the
  contributor. [CONTRIBUTING.md](CONTRIBUTING.md) states up front which changes
  are accepted so that rejection is predictable rather than personal.
- Do not open issues to relitigate a closed scoping decision.

## Reporting

Report unacceptable behavior privately through the repository's
[Security tab](https://github.com/osuki-dev/kit/security) using **Report a
vulnerability** — it is the only private channel this repository has, and it
reaches the maintainers directly. Mention in the first line that the report is
about conduct rather than a vulnerability.

Reports are handled confidentially. The maintainers will respond within 5
working days.

## Enforcement

Maintainers may remove comments, close issues or PRs, or block accounts that
violate this document. Repeated or severe violations result in a permanent ban
from the repository.
